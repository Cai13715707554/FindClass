# 03 · UI 风格

这套风格来自 `docs/Demo.html` 的设计稿。**实现里所有颜色、字号、圆角都从
`app/src/main/java/com/school/nav/ui/theme/Theme.kt` 和 `ui/components/` 取，
不要在业务代码里散落硬编码色值** —— 加新界面时照着本文抄。

一句话概括：**浅灰底 + 白色圆角卡片 + 蓝色主操作 + 绿色「目标/到达」语义 + 大留白**。

---

## 一、设计原则

1. **一屏一件事**。首页三张卡片（当前位置 / 要去哪里 / 导航指令）按用户的操作顺序排，
   没有菜单、没有抽屉、没有右上角汉堡。
2. **卡片承载一切**。所有内容都在白色圆角卡片里，卡片间 12 dp 间距。
   不用分割线去切页面，也不用彩色标题栏。
3. **主色只表示「可操作」和「当前」**。蓝色 = 可点的按钮 / 选中态 / 目标名高亮；
   绿色 = 「要去哪里」和「导航指令」的语义圆点。其余一律黑白灰。
4. **地图页反过来**：地图占满全屏，控件都是浮在上面的小卡片 / 圆按钮，
   绝不把地图压在下面留半屏给面板 —— 画轮廓时视野越大越好。
5. **不用 Material 的水波纹**。胶囊导航、快捷 chip、行内文字按钮都显式
   `indication = null`，因为设计稿里是纯色块，涟漪和圆角胶囊叠在一起很脏。

### 2.5 地图覆盖物配色

地图是卫星底图（偏暗、偏绿褐），所以覆盖物用**高饱和 + 描白边**才看得清。

| 对象 | 填充 | 描边 | 底色透明度 |
| --- | --- | --- | --- |
| 楼栋外轮廓 | `#3316B364` | `#16B364`（6 px） | 20% |
| 教室 / 办公室 | `#3300C2D1` | `#00C2D1`（5 px） | 20% |
| 楼梯口（跨层转向点，最关键） | `#33FF8A00` | `#FF8A00`（5 px） | 20% |
| 卫生间（中性，不抢视线） | `#338A90A0` | `#8A90A0`（5 px） | 20% |
| 绘制中的草稿 | `#332F6BFF` | `#2F6BFF`（4 px） | 20% |
| 单点元素标记 | 按类型色 | 白（3 px） | 实心 |
| 选中图形的顶点手柄 | `#FFFFFF` | `#2F6BFF`（4 px） | 实心 |
| 当前正在拖的顶点 | `#FF8A00` | 白（4 px） | 实心 |

**语义约定**：橙色 = 楼梯口（导航里的关键转向点），所以它同时也是「正在编辑的顶点」色 ——
两者都是「这是重点，看这里」。灰色留给卫生间，避免一屏都是彩色。

| 常量 | 值 | 说明 |
| --- | --- | --- |
| `POINT_ELEMENT_RADIUS_M` | 6.0 m | 单点元素标记半径 |
| `VERTEX_DOT_RADIUS_M` | 3.5 m | 顶点手柄半径 |

> ⚠️ 这两个值是**按米**给的，会随缩放变化。大屏手机 / 高缩放下可能偏小，待真机确认。

## 三、字体

`NavTypography` 只覆写了 5 个档位，其余用 Material3 默认：

| 档位 | 字号 | 字重 | 字距 | 用在哪 |
| --- | --- | --- | --- | --- |
| `titleLarge` | 20 sp | Bold | 0.5 sp | 页面标题（「校园教学楼导航」「设置」「我的」） |
| `titleMedium` | 17 sp | SemiBold | — | 卡片内的次级标题 |
| `bodyLarge` | 16 sp | — | — | 导航指令正文、搜索候选名 |
| `bodyMedium` | 14 sp | — | — | 提示、副标题、配置行的时间 |
| `labelMedium` | 12 sp | Medium | 0.6 sp | `SectionLabel` 小标题（「当前位置」） |

**业务代码里的临时字号**（都是刻意的，不是偷懒）：

| 场景 | 字号 | 理由 |
| --- | --- | --- |
| 位置主文案（`A栋 · 3楼 · 语文教研室`） | 18 sp SemiBold | 这是全屏最重要的信息，比 `titleMedium` 再大一号 |
| 导航栏文字 | 16 sp | 比 Material 默认大，胶囊里看着才不空 |
| 说明性长文（设置页的解释） | 13 sp / 12 sp | 卡片里塞得下更多字 |
| 地图页搜索框 / 模式下拉 | 14 sp | 浮在地图上，大了会挡视野 |
| 圆形工具图标 | 19 sp（`size(19.dp)`） | 配 42 dp 的圆按钮 |

## 四、形状、间距、阴影

### 4.1 圆角（`NavShapes`）

| 档位 | 值 | 用在哪 |
| --- | --- | --- |
| `extraSmall` | 8 dp | 搜索候选行 |
| `small` | 10 dp | 输入框、卡片内的小按钮 |
| `medium` | 16 dp | **主卡片**、底部编辑器的状态卡 |
| `large` | 22 dp | 大浮层 |
| `extraLarge` | 28 dp | — |

**不在 Shapes 里的两个特例**：

- 底部导航栏：`RoundedCornerShape(percent = 50)` —— 完整胶囊；
- 地图页的搜索框 / 模式下拉：`RoundedCornerShape(24.dp)` —— 固定 24 dp，
  因为它们高度固定，用百分比在展开时形状会跳。

### 4.2 间距

| 项 | 值 | 说明 |
| --- | --- | --- |
| 页面左右内边距 | 12 dp | 首页 / 我的 / 设置 / 地图页统一 |
| 页面顶部内边距 | 24 dp（+ 状态栏） | 标题的呼吸位 |
| 卡片之间 | 12 dp | `Arrangement.spacedBy(12.dp)` |
| 卡片内部 | 16 dp | `NavCard` 固定 |
| 卡片内元素间 | 4 / 6 / 8 / 10 / 14 dp | 按语义分档，不滥用 |
| 底部预留 | `NavBarSpace = 88 dp` | 56 dp 导航栏 + 12×2 外边距 + 余量 |
| 圆形工具按钮间距 | 8 dp | 右侧竖排 |
| 地图页顶部栏 | 12 dp 左右 / 10 dp 上下 | 浮层的紧凑内边距 |

### 4.3 阴影（用 `shadowElevation` 表达层级）

| 层级 | 值 | 对象 |
| --- | --- | --- |
| 页面卡片 | 2 dp | `NavCard` |
| 无 Key 引导卡 | 4 dp | 居中浮层 |
| 圆形工具按钮 | 4 dp | 地图上的小圆按钮 |
| 搜索框 / 模式下拉 / 结果面板 | 6 dp | 地图顶部浮层 |
| 底部导航胶囊 | 8 dp | 最高层级，永远盖在内容上 |

**浮动元素的层级顺序**（`AppShell` 的 `Box`）：地图 → 页面内容 → 底部导航。
底部导航放最后，保证它画在最上层且始终可点。

## 五、组件清单

### 5.1 `NavCard` — 卡片容器

```
白色 · 16 dp 圆角 · 16 dp 内边距 · 2 dp 阴影 · 铺满宽度
```

所有内容卡片的唯一入口。不要在页面里直接用 Material 的 `Card`，
否则圆角 / 底色 / 阴影会各写一遍然后慢慢跑偏。

### 5.2 `SectionLabel` — 卡片小标题

```
● 当前位置
```

6 dp 圆点 + `labelMedium`，圆点默认 `Brand`，可传 `dotColor`。
首页「要去哪里」「导航指令」两张卡传 `Green`，其余用默认蓝。
**圆点不是装饰**：它让三张卡片的视觉节奏一致，一眼能看出「这一块在讲什么」。

### 5.3 `BottomNavBar` — 悬浮胶囊导航

| 属性 | 值 |
| --- | --- |
| 形状 | 完整胶囊，左右各留 16 dp，不贴屏幕两边 |
| 高度 | 56 dp |
| 选中项 | 白色胶囊底 + 图标 + SemiBold 文字，横向内边距动画 12 → 20 dp |
| 未选中项 | 只有文字，颜色更淡 |
| 图标 | 仅选中项显示，18 dp |
| 动效 | 颜色与内边距用 `animateColorAsState` / `animateDpAsState` |

**刻意不用 Material3 的 `NavigationBar`**：它的高度、击中区域和选中指示器都按
Material 规范固定，改造成这个悬浮胶囊要覆盖的属性比直接画还多。

三个页签：首页 / 地图 / 我的。「地图」用 `Icons.Filled.Edit`（画笔），
比地图图标更能表达「这一页是编辑器」。

### 5.4 `PositionCard` — 当前位置

```
● 当前位置
A栋 · 3楼 · 语文教研室          ← 18 sp SemiBold
室内信号弱，沿用上次锁定的楼栋。    ← 14 sp 次要色，可能不显示
[  修改位置  ] [  重新定位  ]     ← 两个等宽 OutlinedButton
```

- 楼栋、楼层用 `TextPrimary`，**元素名用 `Brand` 高亮** —— 三者里用户最关心「我具体在哪间屋」。
- 楼层未确定时显示「楼层待确认」并降级为次要色。
- 定位中显示 14 dp 的 `CircularProgressIndicator` + 「定位中…」。
- 提示行可能为空；为空时用 `Spacer(4.dp)` 占位，避免按钮位置跳动。

### 5.5 `TargetSearchCard` — 要去哪里

```
● 要去哪里                       ← Green 圆点
[ 输入教室名，如 物理实验室 ] [ 导航 ]
  （聚焦且有候选时，下方出现最多 220 dp 高的滚动候选列表）
快捷目标
(物理实验室) (教务处) (图书馆) …
```

- 输入框：`OutlinedTextField`，未聚焦底色 `FieldBackground`、描边 `Divider`；
  聚焦时底色变白、描边变 `Brand`。键盘 `ImeAction.Search`。
- 候选行：左中文名（`bodyLarge`）+ 右「楼栋 · 楼层」（`bodyMedium` 次要色），
  两端对齐。这条右侧信息很关键 —— 重名教室靠它区分。
- 快捷目标：`FlowRow` 自动换行的圆角胶囊（20 dp 圆角，`ChipBackground` 底，
  13 sp `ChipText`），横向 13 dp / 纵向 7 dp 内边距。

### 5.6 `RouteCard` — 导航指令

```
● 导航指令                       ← Green 圆点
先沿走廊向东走，经过计算机房，到东楼梯口，上到 3 楼。   ← 16 sp，行距 24
出楼梯后，沿走廊向东走，经过…
目标教务处就在正前方。
```

- 一条文案一段，段间 6 dp。
- **目标中文名用 `Brand` + SemiBold 高亮**（`buildAnnotatedString` 切分拼接）。
  高亮词由 `RouteStep.highlight` 给出；找不到该词时**退化成纯文本**，不报错。

### 5.7 `EditPositionSheet` — 修改位置弹层

底部弹层，三级联动下拉（楼栋 → 楼层 → 当前位置）。用弹层而不是新页面：
用户改完位置就想立刻看到导航变化，跳页面会把导航结果挤出视野。

### 5.8 地图页浮层

| 组件 | 外观 |
| --- | --- |
| 搜索框（收起） | 24 dp 圆角白胶囊，`Search` 图标 18 dp + 「搜索地点」14 sp 次要色，右侧 6 dp 阴影 |
| 搜索框（展开） | 同一胶囊里换成无边框输入框 + 右侧「取消」13 sp，自动聚焦弹键盘；搜索中把尾部图标换成 16 dp 转圈 |
| 模式下拉 | 固定 84 dp 宽的白胶囊，「教学楼 ▾」14 sp `Brand` Medium；搜索展开时**宽度动画到 0 并淡出** |
| 搜索结果面板 | 贴搜索框下方的白卡片，`expandVertically` 拉出来 |
| 圆形工具 | 42 dp 白圆 + 19 dp 图标 + 4 dp 阴影，间距 8 dp；开关态（编辑模式）时底色变 `Brand`、图标变白；禁用时图标 40% 透明 |
| 底部状态条 | 16 dp 圆角白卡，两行文字 + 右侧「清单」+ 下方「成面 / 保存导入」两个等宽按钮 |

**关键细节**：

- 顶部整块加 `windowInsetsPadding(WindowInsets.statusBars)`。
  早期搜索框直接顶到屏幕最上沿，被状态栏的时间/信号图标盖住，点不到也看不清。
- 结果面板**不用半透明全屏遮罩** —— 那样会把地图糊一层白，
  用户挑地点时反而看不到地图。只是一块贴着搜索框的圆角面板。
- 编辑类工具按钮（旋转 / 加点 / 删点 / 删除图形）**只在编辑模式下出现**，
  否则右侧会堆一列平时用不到的按钮。
- 「放弃当前绘制」只在有草稿时出现。

### 5.9 弹窗

| 弹窗 | 内容 |
| --- | --- |
| 命名弹窗 | 名称输入框；教学楼 / 自由轮廓模式额外显示「楼层数」输入 + `-` / `+` 步进 |
| 绘制清单 | 楼栋 → 楼层 → 元素三级列表，可改楼层数、删楼栋、删元素、重新加载 |
| 新建 / 重命名配置 | 名称输入框，附一句「名字会直接当作文件名，自动加 .json」 |
| 删除配置确认 | 红字路径效果 + 「删了没法恢复」+ 删除 / 取消 |

### 5.10 「没配 Key」引导卡

居中白卡 + 说明文字 + 「去设置里填写 Key」按钮。
**地图 SDK 缺 Key 只会白屏**，那种失败方式对用户毫无帮助，所以必须自己拦一层。

## 六、文案风格

| 规则 | 例子 |
| --- | --- |
| 全中文，不夹英文术语 | 「要去哪里」而不是「Destination」 |
| 说清「为什么」和「怎么办」，不只报错 | 「没有定位权限，请点"修改位置"手动选择当前位置。」 |
| 导航文案不出现米数和教室编号 | 「沿走廊向东走，经过计算机房，到东楼梯口」 |
| 按钮用动词短语 | 「保存导入」「重新定位」「放弃当前绘制」 |
| 提示语用第二人称，像在指路 | 「按住拖动框出范围（不用逐点点选）」 |
| 状态提示带数量，让用户知道还差多少 | 「已落 2 个点，至少还要 1 个」 |
| 括号里放「为什么不用做某件事」 | 「点一下放置楼梯口（不用拖、不用画边界）」 |
| 不用感叹号、不卖萌 | — |

## 七、明确不用的东西

| 不用 | 原因 |
| --- | --- |
| Material3 `NavigationBar` | 改造成悬浮胶囊要覆盖的属性和直接画一样多 |
| Material 水波纹（`ripple`） | 和纯色圆角胶囊叠加很脏；设计稿里就是纯色块 |
| 高德自带控件（缩放按钮 / 指南针 / 比例尺 / 定位按钮） | 它自己的视觉语言和本应用摆在一起很割裂。缩放用双指就够 |
| 全屏半透明遮罩 | 地图页会糊掉地图；首页弹层用底部 sheet 更自然 |
| 彩色渐变 / 大图 banner / 阴影堆叠 | 这是一个工具，不是营销页 |
| 深色模式 | 未做。所有色值都写在浅色 `lightColorScheme` 里 |
| 自定义字体 | 未做。用系统默认字体 + 字号字重区分层级 |

## 八、加新界面时的检查清单

- [ ] 内容放在 `NavCard` 里了吗？卡片间距 12 dp、页面左右内边距 12 dp？
- [ ] 卡片有小标题吗？用了 `SectionLabel` 和「该用哪个颜色」的圆点吗？
- [ ] 颜色是从 `NavColors` 取的吗？（搜索一下代码里有没有新的 `Color(0x...)`）
- [ ] 字号是从 `MaterialTheme.typography` 取的吗？如果写死了，理由是什么？
- [ ] 圆角用 `MaterialTheme.shapes.*` 了吗？
- [ ] 底部留了 `NavBarSpace` 吗？（否则内容会被悬浮导航盖住）
- [ ] 顶部避开了状态栏吗？（`windowInsetsPadding(WindowInsets.statusBars)`）
- [ ] 浮层元素的 `shadowElevation` 符合 §4.3 的层级表吗？
- [ ] 有没有用到「明确不用」里的东西？
- [ ] 新增的可交互控件加 `TestTags` 了吗？（纯 UI 改动也要更新 Compose 测试标签）
